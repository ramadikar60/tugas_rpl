## 🌟 Tentang MINDORA

**MINDORA** adalah workspace digital serba-bisa untuk menulis, merencanakan, dan mengorganisir apapun. Dirancang untuk pelajar, penulis, developer, peneliti, dan siapa saja yang butuh satu tempat untuk semua catatan dan ide.

### Apa Arti MINDORA?

| Huruf | Kepanjangan | Makna |
|:-----:|-------------|-------|
| **M** | **Mind** | Ruang untuk pikiran dan gagasan Anda |
| **I** | **Ideas** | Tempat ide lahir, tumbuh, dan saling terhubung |
| **N** | **Notes** | Catatan kaya fitur dengan editor tingkat lanjut |
| **D** | **Documents** | Dokumen, file, dan media dalam satu pustaka |
| **O** | **Organization** | Folder, tag, proyek, tugas, dan kanban |
| **R** | **Research** | Web clipper, sumber referensi, dan citation generator |
| **A** | **Archive** | Arsip, riwayat versi, dan pengetahuan jangka panjang |

> **Satu Ruang untuk Semua Ide.**

### Kenapa MINDORA?

- ⚡ **Ringan & Cepat** — dibangun dari teknologi minimalis, tanpa framework berat
- 🎨 **Editor Kaya** — dukungan markdown, tabel, matematika, diagram, dan embed
- 🔗 **Terhubung** — hubungkan catatan dengan wiki links, mention, dan graph view
- 🔒 **Aman** — enkripsi, CSRF protection, rate limiting, dan kontrol akses granular
- 📱 **Responsif** — nyaman dipakai di desktop, tablet, maupun mobile
- 🎯 **All-in-One** — catatan, tugas, kalender, kanban, mind map, whiteboard, dan banyak lagi

## 🛠️ Tech Stack

MINDORA dibangun dengan filosofi **"back to basics"** — tanpa framework berat, tanpa dependency berlebihan. Hasilnya: aplikasi yang ringan, cepat, dan mudah dimodifikasi.

### Backend
| Teknologi | Fungsi |
|-----------|--------|
| **Go 1.21+** | Bahasa utama backend |
| **net/http** | HTTP server (standard library, tanpa framework) |
| **MySQL 8.0+** | Database relasional |
| **JWT** | Autentikasi access token |
| **CSRF token** | Proteksi dari cross-site request forgery |
| **Rate limiting** | Token bucket algorithm |

### Frontend
| Teknologi | Fungsi |
|-----------|--------|
| **HTML5** | Struktur halaman |
| **CSS3** | Styling dengan custom properties & responsive design |
| **Vanilla JavaScript** | Logika aplikasi (tanpa React/Vue) |
| **Quill 2** | Rich text editor |
| **KaTeX** | Render matematika |
| **Mermaid** | Diagram & flowchart |
| **Highlight.js** | Syntax highlighting |
| **Inter Font** | Tipografi modern |

### Arsitektur
```
┌─────────────────┐         ┌─────────────────┐
│                 │  HTTP   │                 │
│  Browser        │ ◄─────► │  Go Backend     │
│  (Frontend)     │  JSON   │  (net/http)     │
│                 │         │                 │
└─────────────────┘         └────────┬────────┘
                                     │
                                     │ SQL
                                     ▼
                            ┌─────────────────┐
                            │                 │
                            │  MySQL          │
                            │  Database       │
                            │                 │
                            └─────────────────┘
```

- **Backend** menyajikan REST API (~150 endpoint) + file statis
- **Frontend** vanilla JS memanggil API via `fetch()`
- **Autentikasi** via JWT di header `Authorization` + refresh token di cookie
- **File upload** disimpan di folder `uploads/` lokal

## ⚙️ Instalasi Cepat

```bash
# 1. Clone repository
git clone https://github.com/USERNAME/mindora-app.git
cd mindora-app

# 2. Install dependencies
go mod download

# 3. Setup database
mysql -u root -p -e "CREATE DATABASE mindora_db CHARACTER SET utf8mb4;"
mysql -u root -p mindora_db < schema.sql

# 4. Konfigurasi environment
cp .env.example .env
# Edit .env sesuai setup Anda

# 5. Jalankan
go run main.go
```

Buka `http://localhost:8080` di browser.

**Admin default** akan otomatis dibuat dengan kredensial dari `.env`:
- Email: `admin@mindora.local`
- Password: `admin123`

> ⚠️ **Segera ganti password** setelah login pertama!

## 🔌 API Overview

MINDORA menyediakan **~150 REST endpoint** dengan prefix `/api`.

### Contoh Endpoint Utama

| Kategori | Contoh Endpoint |
|----------|-----------------|
| **Auth** | `POST /api/auth/login`, `POST /api/auth/register` |
| **Profile** | `GET /api/profile`, `POST /api/profile/change-password` |
| **Notes** | `GET /api/notes`, `POST /api/notes`, `PUT /api/notes/{id}` |
| **Notebooks** | `GET /api/notebooks`, `POST /api/notebooks` |
| **Tasks** | `GET /api/tasks`, `POST /api/tasks/{id}/toggle` |
| **Calendar** | `GET /api/calendar/events`, `GET /api/calendar/day` |
| **Projects** | `GET /api/projects`, `POST /api/projects` |
| **Kanban** | `GET /api/boards`, `POST /api/cards/{id}/move` |
| **Mind Maps** | `GET /api/mindmaps`, `POST /api/mindmaps/from-note` |
| **Whiteboards** | `GET /api/whiteboards`, `PUT /api/whiteboards/{id}` |
| **Search** | `GET /api/search`, `GET /api/search/advanced` |
| **Sharing** | `POST /api/shares`, `GET /api/shares/with-me` |
| **Admin** | `GET /api/admin/users`, `POST /api/admin/users` |

Semua endpoint terproteksi memerlukan header:
```
Authorization: Bearer <access_token>
X-CSRF-Token: <csrf_token>  (untuk POST/PUT/DELETE)
```

## 🔒 Keamanan

MINDORA mengambil keamanan dengan serius:

- ✅ **Password hashing** dengan SHA-256 + salt unik per user
- ✅ **JWT** dengan HMAC-SHA256, access token 15 menit
- ✅ **Refresh token** disimpan di database, dapat direvoke
- ✅ **CSRF protection** untuk semua endpoint mutasi
- ✅ **Rate limiting** per IP (global & auth khusus)
- ✅ **SQL injection prevention** via prepared statements
- ✅ **XSS prevention** dengan HTML escaping
- ✅ **Auto-logout** semua device setelah ubah password
- ✅ **Role-based access control** (Admin / User / Viewer)
- ✅ **Password-protected shares** dengan expiry date
